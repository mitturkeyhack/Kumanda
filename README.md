# Kumanda

A35'ten diğer telefonları (Huawei Y7 2019, Redmi Note 8) internet üzerinden yönetme uygulaması.

- Ses: kapat / kıs / orta / sonuna kadar
- TikTok ve YouTube engeli ("şu an çalışmıyor" uyarısı) + gece engeli (saatli)
- Wi‑Fi aç / süreli kapat, Bluetooth aç / kapat
- Ekranı kilitle, durum sor

Aynı APK üç telefona da kurulur: A35'te **Kumanda**, diğerlerinde **Alıcı** seçilir.
